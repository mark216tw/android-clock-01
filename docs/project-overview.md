# 專案說明

## 專案定位

「簡單時鐘」是面向床頭、桌面及日常提醒情境的 Android 時鐘應用程式。產品核心是清楚的大型時間顯示、可個人化的時鐘外觀、可恢復的本機鬧鐘排程，以及不依賴網路的桌面小工具。

專案目前處於 Pre-release 階段，重點是驗證功能、裝置相容性與鬧鐘可靠性，不代表正式穩定版本。

## 功能範圍

### 大型時鐘

- 顯示時間、日期、秒數及上午／下午資訊。
- 支援 12 小時、24 小時及跟隨系統格式。
- 支援直向、橫向、全螢幕及常亮。
- 直向與橫向畫面可分別設定五級尺寸。
- 點擊畫面可顯示或隱藏底部操作列。

### 時鐘樣式

時鐘樣式依設定選單順序分為三類：

| 分類 | 數量 | 樣式 |
| --- | ---: | --- |
| 數字時鐘 | 8 | 極簡、細字、霓虹燈、動態光暈、鏤空、LED、液態玻璃、復古輝光管 |
| 圓形指針 | 4 | 經典指針、極簡指針、包浩斯幾何、瑞士國鐵 |
| 方形指針 | 4 | 方形經典、方形極簡、復古方鐘、方形羅馬鐘 |

方形指針樣式使用固定直立長方形畫布，高度：寬度為 `1.20:1`。系統字型用於數字與羅馬數字，專案沒有加入外部字型。

### 主題與背景

- App Material 介面色彩與主時鐘展示色彩互相獨立。
- 介面支援六個系統色彩預設、自訂 Hue、淺色、深色及跟隨系統。
- 時鐘背景支援純色和彩色配色。
- 彩色配色可隨機產生、立即保存、重新選用及刪除。
- 九種背景紋路可搭配單一動態開關。

### 鬧鐘

- 多組單次或每週重複鬧鐘。
- 名稱、星期、識別色及手動排序。
- 下一次響鈴日期和倒數資訊。
- 精準排程、提前通知、響鈴、停止及延後。
- 開機、App 更新、時間和時區變更後重新整理排程。

### 桌面小工具

- 一列式可調寬度 Widget。
- 顯示時間、日期及系統下一個鬧鐘。
- 各 Widget 實例獨立保存配色、模式、背景及字級。

## 非功能目標

- **離線優先**：核心功能不依賴網路或遠端服務。
- **即時回饋**：設定先更新畫面，再非同步保存。
- **排程可信度**：AlarmManager 排程使用 Room Occurrence 作為持久化憑證。
- **平台整合**：採用系統精準鬧鐘、通知、全螢幕 Intent 與下一個鬧鐘資訊。
- **可存取性**：色彩選項與時鐘樣式提供選取語意，Canvas 指針鐘提供時間描述。

## 系統需求

| 項目 | 需求 |
| --- | --- |
| 最低 Android | Android 8.0，API 26 |
| 編譯 SDK | API 36 |
| 目標 SDK | API 36 |
| Java | 17 |
| 網路 | 不需要 |

## 已知限制

- Pre-release 使用 Debug Key 簽署，不適合作為正式散布版本。
- 各 Android 廠牌可能額外限制背景執行、通知或精準鬧鐘。
- 桌面小工具外觀可能因 Launcher 尺寸計算而不同。
- 目前沒有雲端同步、匯出／匯入或 Android 標準備份。
- 除 Room `3 → 4` 外，開發期間不相容的資料庫版本可能採破壞性重建。
- 自動化測試目前以 JVM 單元測試為主，尚未完整涵蓋實機權限、通知、Receiver、Service 與 Widget。
