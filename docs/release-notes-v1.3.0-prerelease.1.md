# 簡單時鐘 v1.3.0 Pre-release 1

此版本為 **Pre-release 版本，不是正式上線版本**，主要供功能驗證、裝置相容性測試與使用者回饋。

## 主要內容

- 16 種時鐘樣式，包含 8 種數字、4 種圓形指針及 4 種方形指針。
- 方形指針時鐘使用固定直立長方形比例，高度：寬度為 `1.20:1`。
- 時鐘樣式設定採分類雙欄預覽選單。
- 九種背景紋路、純色／彩色模式及獨立動態選項。
- 「好運氣」可產生、套用並自動保存彩色配色。
- 系統介面色彩與主時鐘色彩可分開設定。
- 多組鬧鐘、重複星期、識別色、下一次響鈴資訊及拖曳排序。
- 提前 10 分鐘通知、停止、延後 10 分鐘及排程恢復。
- 每個實例可獨立設定的桌面小工具。

## 安裝說明

1. 下載 Release Assets 中的 `app-prerelease.apk`。
2. 允許目前瀏覽器或檔案管理器安裝未知來源 App。
3. 安裝後依系統提示允許通知、精準鬧鐘與全螢幕通知。

- 此 APK 使用 Android Debug Key 簽署。
- 此版本不是正式發行版，功能、資料結構與介面仍可能變更。
