# 使用指南

## 安裝

1. 前往專案的 [GitHub Releases](https://github.com/mark216tw/android-clock-01/releases)。
2. 選擇標示為 **Pre-release** 的版本。
3. 下載 `app-prerelease.apk`。
4. 在 Android 裝置開啟 APK。
5. 若系統阻擋安裝，依提示允許目前瀏覽器或檔案管理器安裝未知來源應用程式。

> Pre-release 僅供測試，使用 Debug Key 簽署。若曾安裝使用不同金鑰簽署的同套件 App，可能需要先解除安裝才能安裝此版本。

## 主時鐘

啟動 App 後會進入主時鐘。點擊畫面可顯示或隱藏底部控制列，控制列顯示後約四秒會自動隱藏。

底部控制列提供：

- **鬧鐘**：開啟鬧鐘清單。
- **設定**：調整顯示、色彩、背景與時鐘樣式。
- **畫面方向**：依序切換跟隨系統、直向及橫向。
- **全螢幕**：顯示或隱藏 Android 系統列。
- **關閉**：將 App 移到背景，不會強制終止程序。

## 顯示設定

設定頁分為「系統」與「時鐘」兩個主要區域。

### 顯示模式

可選擇跟隨系統、淺色或深色。此選項影響設定頁、鬧鐘頁及一般 Material 介面。

### 系統色彩

- 提供莓果粉、活力橙、檸檬黃、薄荷綠、晴空藍及電光紫。
- 點擊色塊會立即套用。
- 拖曳 Hue 滑桿可即時預覽自訂色彩。
- 預設色彩與自訂色相分開保存，切回自訂色彩時會恢復先前值。

### 時鐘顯示

- **顯示秒數**：數字時鐘顯示秒數；指針時鐘顯示秒針。
- **冒號閃爍**：數字時鐘的冒號每秒顯示或隱藏。
- **保持螢幕開啟**：時鐘畫面位於前景時避免自動關閉螢幕。
- **時間格式**：跟隨系統、12 小時或 24 小時。
- **時鐘字級**：直向與橫向分別提供五級尺寸。

### 主題與背景

- **主題色彩**：選擇六種預設色或使用 Hue 自訂。
- **背景紋路**：選擇九種紋路，或使用無紋路。
- **動態**：控制目前紋路是否動畫。
- **背景色彩**：選擇純色或彩色。
- **好運氣**：產生新彩色配色、立即套用並保存。
- **已儲存配色**：點擊可重新套用，點擊關閉圖示可刪除。

### 時鐘樣式

樣式依「數字時鐘」、「圓形指針」及「方形指針」分類。點擊預覽卡片即可切換，選中的樣式會顯示外框、淡色背景與勾選圖示。

## 新增鬧鐘

1. 從主畫面點擊「鬧鐘」。
2. 點擊右上角「+新增」。
3. 點擊時間開啟時間選擇器。
4. 輸入名稱，最多 40 個字元。
5. 選擇重複星期；未選星期表示單次鬧鐘。
6. 選擇預設識別色，或拖曳 Hue 滑桿自訂。
7. 點擊「儲存」。
8. 依 Android 提示授予必要權限。

鬧鐘成功排程後，畫面會顯示下一次響鈴時間或剩餘時間。

## 管理鬧鐘

- 點擊鬧鐘卡片可編輯。
- 使用卡片開關可啟用或停用。
- 卡片會顯示下一次響鈴的星期與時間；最早響鈴的已啟用鬧鐘會顯示「下一次響鈴」標記。
- 長按拖曳把手可重新排序。
- 編輯畫面可刪除鬧鐘，目前不會顯示第二次確認。
- 停用鬧鐘會取消目前排程及相關提前通知。

## 權限說明

| 權限或能力 | 用途 |
| --- | --- |
| 通知 | 顯示提前提醒、延後通知及響鈴通知 |
| 精準鬧鐘 | 在指定時間觸發鬧鐘 |
| 全螢幕通知 | 鎖定畫面或背景狀態下開啟響鈴畫面 |
| 前景服務 | 響鈴期間持續播放聲音與振動 |
| 震動 | 鬧鐘響鈴震動 |
| 開機完成 | 裝置重開機後恢復排程 |

若鬧鐘無法正常運作，請檢查 App 通知、精準鬧鐘、全螢幕通知及裝置的背景執行／省電設定。

## 響鈴與延後

- 響鈴畫面可在鎖定畫面顯示並喚醒螢幕。
- 點擊「停止」結束目前鬧鐘。
- 點擊「10 分鐘後提醒」建立延後排程。
- 響鈴最長持續 15 分鐘，之後自動停止。
- 單次鬧鐘完成後會停用；重複鬧鐘會安排下一次。

## 提前通知

一般鬧鐘會在預定時間前 10 分鐘顯示無聲通知。通知可用來開啟鬧鐘頁，或取消本次提醒而不永久刪除重複設定。

## 桌面小工具

1. 在 Launcher 的小工具選單選擇「簡單時鐘」。
2. 將小工具加入桌面。
3. 在設定畫面選擇配色、明暗模式、背景及字級。
4. 點擊「加入小工具」。

小工具操作：

- 點擊時間可開啟本 App。
- 點擊鬧鐘資訊會優先開啟系統下一個鬧鐘的對應頁面；沒有下一個鬧鐘時開啟系統鬧鐘頁。
- 小工具可水平縮放，實際尺寸取決於 Launcher。

## 解除安裝與資料

所有資料保存在裝置本機。解除安裝 App 會刪除鬧鐘、設定及 Widget 設定；目前不提供備份或匯出功能。
